# FolioCheck

Bespoke, tactile client-side checklist workspace for `.xlsx`, `.xls`, `.csv`, and text-based `.pdf` files.

- **100% Client-Side:** Files are parsed and stored locally in your browser (`localStorage`). Nothing is uploaded to any server.
- **Dual Theme:** Warm Paper (Light) and Obsidian Tactical (Dark) modes with `prefers-color-scheme` support.
- **Live Site:** https://vinhosen.github.io/folio-check/
